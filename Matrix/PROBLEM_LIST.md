# Matrix — Problem List from the supplied workbook

1. Traverse a matrix in spiral form.
2. Search for a target in a row-wise sorted matrix with O(log(m × n)) time.
3. Find the median in a row-wise sorted matrix (odd rows and columns).
4. Find the first row with the maximum number of 1s.
5. Sort all elements of a matrix.
6. Find the maximum-area rectangle containing only 1s.
7. Find the maximum mat[c][d] − mat[a][b] where c > a and d > b.
8. Rotate a square matrix 90 degrees clockwise in place.
9. Find the Kth smallest element in a row- and column-wise sorted matrix.
10. Find all elements common to every row.
11. Check whether a square matrix is invertible.
12. Represent a sparse matrix using triplets.
13. Find the largest square submatrix containing only 1s.
14. Find the trace and normal (Frobenius norm) of a matrix.
15. Print the lower triangular matrix.
16. Print the upper triangular matrix.
17. Perform message encoding using matrix multiplication.
18. Find the LU decomposition of a matrix.
19. Find the determinant of a matrix.
20. Find the sum and product of all matrix elements.
