# Number System — Problem List from the Workbook

1. Armstrong Number — determine whether the sum of each digit raised to the number of digits equals the given positive integer.
2. Automorphic Number — the square ends in the same digits as the number itself.
3. Buzz Number — ends with digit 7 or is divisible by 7.
4. Circular Prime — every cyclic permutation of its digits is also prime.
5. Co-Prime Numbers — two numbers whose GCD is 1.
6. Digit to Word — convert a given number to words.
7. Duck Number — contains zeroes but no zero at the beginning.
8. Factorial — find the factorial of a given number.
9. Factors — display the factors of a given number.
10. Fibonacci Series — display the Fibonacci series for a given range.
11. Floyd Triangle — display numbers in Floyd Triangle pattern.
12. GCD — find the GCD of two or more integers, not all zero.
13. Happy Number — find the happy numbers from the given input.
14. Harshad Number — divisible by the sum of its digits.
15. LCM — find the LCM of two numbers.
16. Multiply of Digit — multiply the digits in a number.
17. Neon Number — check a number and find Neon numbers between a specified range.
18. Niven Number — divisible by the sum of its digits.
19. Palindrome Number — determine whether a number is a palindrome.
20. Ugly Number — positive number whose prime factors only include 2, 3 and 5.
21. Pronic Number — product of two consecutive integers.
22. Magic Number — workbook wording: a hard-coded numeric value (text value in some cases) that may change later; see the README for the implementation assumption.
23. Tech Number — even-digit number split into two equal parts where the square of their sum equals the original number.
24. Disarium Number — sum of each digit raised to its respective position equals the number.
25. Twisted Prime — the number and its reverse are both prime.
26. Spy Number — sum and product of its digits are equal.
